<objective>
Add scratch buffer reuse to PolarQuant::inner_product() to eliminate per-call Vec allocation in the attention hot path.

Purpose: The inner_product() method is called N times per attention computation (N = sequence length). Currently it allocates a new Vec<f32> on every call. For 8192 tokens at 128-dim, that is 8192 x 512 bytes = 4MB of throwaway allocations per attention pass. A RefCell<Vec<f32>> scratch buffer pre-allocated at construction time eliminates these allocations, targeting 1.5-2x speedup on the inner_product hot path.

Output: Modified `src/polar_quant.rs` with RefCell scratch buffer in PolarQuant<B>.
</objective>

4. Update `inner_product` to use scratch buffer with explicit scope for borrow guard:
```rust
#[must_use]
pub fn inner_product(&self, query: &[f32], key: &QuantizedVector) -> Result<f32> {
    self.check_dim(query.len())?;
    self.check_dim(key.dim)?;

    // Compute rotated query using scratch buffer (avoids allocation).
    // Scope the borrow_mut guard so it drops before we return.
    let dot = {
        let mut scratch = self.scratch.borrow_mut();
        scratch.clear();
        scratch.extend_from_slice(query);
        self.rotation.apply(&mut scratch);

        let indices = bitpack::unpack(&key.packed, key.dim, key.bits)?;

        scratch
            .iter()
            .zip(&indices)
            .map(|(&q, &idx)| q * self.codebook.dequantize_scalar(idx))
            .sum::<f32>()
    }; // borrow_mut guard dropped here

    Ok(dot * key.norm)
}
```
