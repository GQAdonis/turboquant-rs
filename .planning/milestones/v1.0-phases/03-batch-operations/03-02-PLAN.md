CRITICAL: KvCache contains TurboQuant which contains PolarQuant which has RefCell (!Sync).
KvCache does NOT implement Clone. We need to address this for rayon par_iter.

From src/turboquant.rs:
```rust
pub struct TurboQuant<B: Backend = ScalarBackend> {
    mse: PolarQuant<B>,
    prod_polar: Option<PolarQuant<B>>,
    qjl: Option<Qjl>,
    bits: u8,
}
// NOTE: TurboQuant does NOT derive Clone
```

Since KvCache is not Clone and TurboQuant is not Clone, we cannot use map_init with self.clone().
For batch_attend, the parallelism is across queries, but each attend() call needs the full KvCache.
Options:
1. Make TurboQuant and KvCache Clone (preferred - enables same pattern as PolarQuant)
2. Use scoped threads that borrow (complex)
3. Sequential batch with potential future parallelism

Option 1 is correct: implement Clone for TurboQuant and KvCache.

   **batch_attend:**
   ```rust
   /// Compute attention for multiple queries in parallel.
   ///
   /// Each query independently computes logits -> softmax -> weighted sum
   /// against all cached entries. Parallelism is across queries, not within
   /// a single attention computation.
   ///
   /// # Performance
   /// - Batch-of-1: delegates to `attend()` directly (zero overhead)
   /// - Batch >= 2: parallel processing via rayon work-stealing
   #[must_use = "attention outputs should be used"]
   pub fn batch_attend(&self, queries: &[Vec<f32>]) -> Result<Vec<Vec<f32>>> {
       if queries.is_empty() {
           return Ok(vec![]);
       }
       if queries.len() == 1 {
           return Ok(vec![self.attend(&queries[0])?]);
       }
       // Validate dimensions up front
       for q in queries {
           if q.len() != self.head_dim {
               return Err(crate::error::TurboQuantError::DimensionMismatch {
                   expected: self.head_dim,
                   got: q.len(),
               });
           }
       }
       queries.par_iter()
           .map_init(|| self.clone(), |cache, q| cache.attend(q))
           .collect()
   }
   ```

   **batch_attend_slices:**
   ```rust
   /// Zero-copy variant accepting borrowed slices.
   #[must_use = "attention outputs should be used"]
   pub fn batch_attend_slices(&self, queries: &[&[f32]]) -> Result<Vec<Vec<f32>>> {
       if queries.is_empty() {
           return Ok(vec![]);
       }
       if queries.len() == 1 {
           return Ok(vec![self.attend(queries[0])?]);
       }
       for q in queries {
           if q.len() != self.head_dim {
               return Err(crate::error::TurboQuantError::DimensionMismatch {
                   expected: self.head_dim,
                   got: q.len(),
               });
           }
       }
       queries.par_iter()
           .map_init(|| self.clone(), |cache, q| cache.attend(q))
           .collect()
   }
   ```
